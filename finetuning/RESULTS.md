# 首轮 Tetris SFT 结果

2026-10-16，在指定的现有 EC2 `i-0daca64f56056aa1c` 上完成训练及独立评估。
使用 NVIDIA L4 24GB，冻结 Qwen3.5-2B 基座，续训原始 Decider v19 的
LoRA 和 pointer head。训练数据由游戏引擎自动标注；没有 GPT 教师调用，也没有运行 RL。

## 独立测试

测试集含 2,068 道比较题，与训练、验证及温度校准数据按种子和可观察棋盘隔离。
最佳检查点仅按验证集选择。每道题有一个在指定六项指标上严格支配其他候选的答案。

| 指标 | 原始 v19 | SFT |
| --- | ---: | ---: |
| 独立测试题准确率 | 60.35% | 99.95% |
| 候选反序并重命名后的准确率 | 62.33% | 99.90% |
| 两次选择的实际落点一致率 | 35.44% | 99.85% |

## 完整对局

每个模型使用相同的五个新种子 `50000–50004`，每种输入各跑五局，每局最多 50 块。
对局经过原应用的候选分组及落点执行流程，不使用启发式替换模型的选择。

| 模型 | 输入 | 达到 50 块上限 | 平均落块 | 平均消行 | 指标劣选 / 总落块 |
| --- | --- | ---: | ---: | ---: | ---: |
| 原始 v19 | 数字 | 0/5 | 38.2 | 1.8 | 91/191 |
| 原始 v19 | 自然语言 | 1/5 | 40.8 | 3.0 | 112/204 |
| SFT | 数字 | 5/5 | 50.0 | 12.2 | 17/250 |
| SFT | 自然语言 | 5/5 | 50.0 | 14.2 | 17/250 |

“指标劣选”表示存在另一个候选，在全部六项指标上不差且至少一项更好，
并不等同于长期策略错误。全部 20 局共 895 次落块保存了原始响应和棋盘回放。

## 训练配置与解释

使用 12,590 条训练数据、2,120 条验证数据和 2,090 条单独的校准数据。
训练 1 epoch、787 次优化器更新；micro-batch 2、梯度累积 8；
LoRA 学习率 `2e-5`，决策头学习率 `1e-4`。更新了 16,819,200 个 LoRA 参数和
1,053,184 个决策头参数。最佳检查点为第 787 步，验证准确率 99.95%。
单独校准集选出的 choice 温度为 1.0。

完整训练子进程约 64 分钟；包括预检及前后评估的任务约 83 分钟。
PyTorch 峰值 allocated 显存为 4.50 GiB，此数不包含全部 CUDA 或驱动占用。

结果支持“针对本项目输入的比较训练改善了指标判断和本次短局表现”。
训练中的候选随机排列及随机命名，也与更稳定的实际选择相一致。
但本轮没有消融实验，无法分别归因于 LoRA、决策头或排列增强；
也没有训练长期回报目标。

这些比较题只覆盖可由指标直接判断优劣的候选子集，实战中有取舍的落点仍然可能选错。
对局结果来自单次训练、五个游戏种子和 50 块上限，不能推出无限存活能力，
也不能据此重新排列 Decider、Jev 与 GPT 的总体名次。后续长局测试应使用新种子；
进一步标注有取舍的候选时，可使用搜索或按用户要求使用 GPT 教师。
